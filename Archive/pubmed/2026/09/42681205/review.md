## Review setup
- **Input scope** Full manuscript (Methods in Molecular Biology chapter)
- **Assessment boundary** The manuscript as provided; no supplementary materials or code were supplied.
- **Shared manuscript claim summary** The manuscript presents DisoRDPbind, a web server for predicting RNA-binding intrinsically disordered regions (IDRs), describes its model, performance, and usage, and illustrates its utility via a case study on the HCV core protein.
- **Visible evidence base** The manuscript text, including a description of the predictive model, performance metrics from the CAID experiment, runtime, web server interface instructions, and a case study.
- **Missing materials affecting confidence** No supplementary data, code, or detailed performance tables/figures were provided. The CAID experiment results are referenced but not shown. The case study results are described qualitatively without quantitative validation.

## Reviewer 1
- **Overall assessment** This manuscript provides a useful protocol for using the DisoRDPbind web server, which addresses a niche but important need in the IDR prediction community. The description of the model and its performance is clear, and the case study is a practical addition. However, the manuscript is primarily a methods protocol rather than a primary research article, and its novelty is limited given that DisoRDPbind has been previously published. The evidence for the claims about performance and utility is not fully presented in the supplied material.
- **Who would be interested in the results, and why** Researchers studying RNA-binding proteins, intrinsically disordered regions, and RNA chaperones, particularly those who need a user-friendly tool for large-scale predictions. The protocol format makes it accessible to experimentalists.
- **Major strengths** The manuscript fills a gap by providing a dedicated tool for RNA-binding IDR prediction, which is underrepresented compared to protein-binding IDR predictors. The web server is easy to use and has a small computational footprint, enabling proteome-scale analysis. The case study on HCV core protein demonstrates a practical application.
- **Major Concerns**
    - **Concern ID** R1-M1
    - **Severity** Major
    - **Blocking** Yes
    - **Axis** Evidence sufficiency
    - **Claim pointer** The manuscript claims that DisoRDPbind has "predictive performance and runtime" measured in the second CAID experiment, and that it has a "small computational footprint" allowing "large/proteome-scale predictions."
    - **Evidence pointer** Section: "We describe the predictive model employed by DisoRDPbind and discuss its predictive performance and runtime, which were recently measured in the second CAID (Critical Assessment of protein Intrinsic Disorder) experiment." Location not provided.
    - **Concern** The manuscript does not present any quantitative data (e.g., AUC, precision, recall, runtime in seconds) to support these performance claims. The CAID experiment results are mentioned but not shown, and no figures or tables are provided. The claim about proteome-scale predictions is not backed by any example or benchmark.
    - **Why it matters** Without quantitative evidence, the reader cannot assess whether DisoRDPbind is reliable or competitive compared to other tools. The claims about performance and scalability are central to the tool's utility but remain unsubstantiated in the supplied material.
    - **Resolution test** Provide a table or figure showing key performance metrics (e.g., AUC, MCC, F1) from the CAID experiment, and a benchmark of runtime for a proteome-scale dataset (e.g., number of sequences processed per hour).
    - **Concern ID** R1-M2
    - **Severity** Major
    - **Blocking** No
    - **Axis** Reproducibility
    - **Claim pointer** The manuscript states that DisoRDPbind "does not identify RNA chaperones directly" but presents a case study of HCV core protein to "illustrate the method's utility in studying RNA chaperones."
    - **Evidence pointer** Section: "While DisoRDPbind does not identify RNA chaperones directly, we present a case study of an RNA chaperone, HCV core protein, to illustrate the method's utility in studying RNA chaperones." Location not provided.
    - **Concern** The case study is described qualitatively (e.g., "the method's utility") without showing the actual prediction results for the HCV core protein. It is unclear whether DisoRDPbind correctly predicted RNA-binding IDRs in this protein, or how the results inform RNA chaperone function.
    - **Why it matters** The case study is intended to demonstrate practical utility, but without concrete results (e.g., a figure showing predicted IDRs and RNA-binding regions), the reader cannot evaluate whether the tool is useful for this application.
    - **Resolution test** Include a figure showing the DisoRDPbind prediction output for the HCV core protein, with annotations highlighting predicted RNA-binding IDRs and a brief discussion of how these relate to known chaperone activity.

    - **Concern ID** R1-m1
    - **Severity** Minor
    - **Axis** Clarity

    - **Issue** The manuscript mentions an example but does not include a screenshot or step-by-step visual guide, which is standard for protocol chapters.
    - **Required correction** Add a figure showing the web server interface with numbered steps, or a table summarizing input/output formats.
    - **Concern ID** R1-m2
    - **Severity** Minor

    - **Required correction** Add citations for the CAID experiment (e.g., Necci et al., 2021) and the original DisoRDPbind paper (e.g., Peng et al., 2017).
- **Technical failings that need to be addressed before the case is established** R1-M1 (lack of quantitative performance evidence) is the primary technical failing. Without it, the core claims about the tool's utility are not supported.
- **Assessment against Nature-style criteria** 
    - **Originality** Low. DisoRDPbind has been previously published; this manuscript is a protocol update.
    - **Scientific importance** Moderate. RNA-binding IDRs are an important but understudied area, and a user-friendly tool is valuable.
    - **Interdisciplinary readership** Low. The protocol is targeted at computational and structural biologists, not a broad audience.
    - **Technical soundness** Not assessable from the supplied material due to missing performance data.
    - **Readability for nonspecialists** Good. The text is clear and accessible, with a logical flow.
- **Recommendation posture** Currently not established from the provided evidence. The manuscript would be suitable for a methods/protocols journal if the missing performance data and case study results are added. It does not meet the novelty or evidence standards for a primary research article in Nature.
